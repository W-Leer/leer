# Leer

**Bring clarity to AI agents.**

Leer is an open-source platform to debug, replay, and understand AI agent workflows.

## ✨ Features (MVP)

- 🧠 Full execution timeline
- 🔁 Replay agent runs
- 🔍 Diff runs
- ⚡ Zero-config SDK
- 🏠 Local-first

## 🚀 Vision

AI agents are powerful but opaque.

Leer makes them:
- observable
- testable
- reliable
- production-ready
