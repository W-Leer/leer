# Vision

Leer is the execution record for AI agents: the source of truth for what
an agent did, used to debug it and make it reliable.

## Problem

AI agents are:
- non-deterministic
- hard to debug
- impossible to replay
- fragile in production

Developers cannot answer:
- what happened?
- why did it fail?
- what changed?
- how to reproduce?

## Solution

Leer provides:
- execution records of every run
- step-by-step inspection
- run comparison

Later, built on the same records:
- replay from any point

## Long-term

Leer evolves into:
→ the platform for running reliable AI agents in production
