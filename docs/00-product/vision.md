# Vision

Leer is the debugging and reliability layer for AI agents.

## Problem

AI agents are:
- non-deterministic
- hard to debug
- impossible to replay
- fragile in production

Developers cannot answer:
- what happened?
- why did it fail?
- what changed?
- how to reproduce?

## Solution

Leer provides:
- execution traces
- step-by-step inspection
- replay from any point
- run comparison

## Long-term

Leer evolves into:
→ the platform for running reliable AI agents in production
